# Forever Quests (Horda) — WoW Forever

Diário de cadeias de missões da Horda para o WoW Forever, no estilo do BtWQuests: árvore de cada
cadeia com a história ao lado, missões-ponte entre mapas, missões repetíveis, profissões e
narração gravada (Riverglades).

## Instalar
Baixe o repositório (Code > Download ZIP) e copie a pasta `ForeverQuests` para
`World of Warcraft\_forever_\Interface\AddOns\`.

## Atualizar
Dê dois cliques em `Interface\AddOns\ForeverQuests\Atualizar ForeverQuests.bat`: ele baixa a
versão mais nova deste repositório e copia por cima. Depois, no jogo, `/reload`
(ou feche e abra o jogo se vierem arquivos de som novos).
